# SONG SOD Donate — v1.0.0

เว็บโดเนทของเราเอง: คนดูโดเนท → จอไลฟ์เด้ง **GIF + เพลง + อ่านข้อความเป็นเสียงไทย**

> v1 = **โหมดทดสอบ** (ยังไม่ตัดเงินจริง) · v2 = ต่อ Opn รับ PromptPay / TrueMoney

## หน้าเว็บ

| หน้า | ใช้ทำอะไร |
|---|---|
| `/donate.html` | หน้าโดเนท แจกให้คนดู |
| `/overlay.html` | ใส่ใน OBS (Browser Source) |
| `/admin.html` | กดทดสอบ / ข้ามแจ้งเตือน / ดูรายการ |

## ขั้นที่ 1: ลองรันในเครื่อง

ไม่ต้องลงแพ็กเกจอะไรเพิ่ม (ใช้ Node 18 ขึ้นไป)

```bash
ADMIN_KEY=รหัสของเรา npm start
```

เปิด `http://localhost:3000`

## ขั้นที่ 2: ใส่ GIF และเพลงของเรา

เอาไฟล์ไปวางในโฟลเดอร์ `public/assets/`

- `alert.gif` → ภาพที่เด้ง
- `alert.mp3` → เพลงแจ้งเตือน (สั้น ๆ 3–5 วิกำลังดี)

ถ้าไม่ใส่ จะใช้อีโมจิ 🎉 + เสียงติ๊งแทนให้อัตโนมัติ
(ใช้ไฟล์ที่เรามีสิทธิ์ใช้ เช่นทำเองหรือจากเว็บแจกฟรีที่อนุญาตให้ใช้ในไลฟ์)

## ขั้นที่ 3: ใส่ใน OBS

1. Sources → **+** → **Browser**
2. URL: `https://เว็บของเรา/overlay.html`
3. ขนาด 800 × 600
4. ติ๊ก **Control audio via OBS** (เสียงจะเข้าไลฟ์)
5. ไปหน้า `/admin.html` กด **ยิงทดสอบ** → ต้องเด้งใน OBS

ตัวเลือกเพิ่มเติมใน URL overlay:
- `?vol=0.5` ปรับความดัง (0–1)
- `?gif=ลิงก์gif` ใช้ GIF จากที่อื่น
- `?debug` แสดงสถานะการเชื่อมต่อมุมซ้ายบน

## ขั้นที่ 4: ขึ้นออนไลน์ด้วย Render

1. อัปโค้ดขึ้น GitHub
2. Render → New → **Web Service** → เลือก repo
3. Build: เว้นว่าง หรือ `npm install` · Start: `npm start`
4. Environment Variables:

| ชื่อ | ค่า |
|---|---|
| `ADMIN_KEY` | รหัสแอดมิน (ตั้งให้ยาก ๆ) |
| `STREAMER_NAME` | ชื่อที่โชว์บนหน้าโดเนท |
| `MIN_AMOUNT` | ขั้นต่ำ (ค่าเริ่ม 10) |
| `BAD_WORDS` | คำหยาบเพิ่มเติม คั่นด้วย `,` |
| `TEST_MODE` | `true` (v1) |

⚠️ Render แบบฟรีจะหลับเมื่อไม่มีคนใช้ ตอนเปิดครั้งแรกจะช้าประมาณ 1 นาที — เปิดหน้า admin ก่อนไลฟ์ให้มันตื่น

⚠️ โหมดทดสอบ = ใครมีลิงก์ก็กดเด้งได้ (มีกันกดรัว 5 วิ/คน) อย่าเพิ่งแจกลิงก์ให้คนดูจนกว่าจะเป็น v2

## ระบบกันป่วน

- กรองคำหยาบ → เปลี่ยนเป็น `***`
- ลบลิงก์ในข้อความ
- ข้อความยาวสุด 150 ตัว, ชื่อ 30 ตัว
- เข้าคิว ไม่เด้งซ้อนกัน
- ปุ่ม **ข้าม** ในหน้าแอดมิน

## เสียงอ่าน

ใช้ Google Translate TTS (ไม่ใช่ API ทางการ อาจใช้ไม่ได้วันหนึ่ง) ถ้าใช้ไม่ได้จะสลับไปใช้เสียงอ่านของเบราว์เซอร์เอง
