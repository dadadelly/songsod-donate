# SONG SOD Donate — v1.2.0

เว็บโดเนทของเราเอง: คนดูโดเนท → จอไลฟ์เด้ง **GIF + เพลง + อ่านข้อความเป็นเสียงไทย**

> v1.1 = **QR PromptPay ของเราเอง** + แอดมินกดอนุมัติก่อนเด้ง
> (ถ้ายังไม่ใส่ `PROMPTPAY_ID` จะเป็นโหมดทดสอบ)

## วิธีรับเงิน (v1.1)

1. คนดูกรอกชื่อ/ยอด/ข้อความ → ได้ QR PromptPay ตามยอด
2. สแกนจ่าย → กด **โอนแล้ว**
3. หน้า `/admin.html` ส่วน **รออนุมัติ** จะมีเสียงเตือน
4. เปิดแอปธนาคารเช็กว่าเงินเข้าจริง → กด **อนุมัติ** → เด้งบนจอ
5. ไม่พบเงิน → กด **ไม่พบเงิน** (ไม่เด้ง)

รายการที่ไม่อนุมัติภายใน 30 นาทีจะหายไปเอง

## หน้าเว็บ

| หน้า | ใช้ทำอะไร |
|---|---|
| `/donate.html` | หน้าโดเนท แจกให้คนดู |
| `/overlay.html` | ใส่ใน OBS (Browser Source) |
| `/admin.html` | กดทดสอบ / ข้ามแจ้งเตือน / ดูรายการ |

## TikTok LIVE: อ่านคอมเมนต์ + ขอบคุณคนกดติดตาม (v1.2)

1. Render → Environment เพิ่ม `TIKTOK_USERNAME` = ชื่อ TikTok (ไม่ต้องมี @)
2. Build Command ต้องเป็น `npm install` (หรือ `yarn install`) เพื่อติดตั้งตัวเชื่อม TikTok
3. ใส่ Link Source ใน LIVE Studio:
   - อ่านคอมเมนต์: `/tiktok.html?show=chat`
   - ขอบคุณผู้ติดตาม: `/tiktok.html?show=follow`
   - หรือรวมอันเดียว: `/tiktok.html`
4. หน้า admin → ส่วน **TikTok LIVE** → **เชื่อมต่อ** (กดก่อนไลฟ์ได้ ระบบจะลองต่อเองจนกว่าจะเริ่มไลฟ์)

| ตั้งค่าเพิ่ม (ไม่ใส่ก็ได้) | ค่าเริ่มต้น |
|---|---|
| `FOLLOW_TEXT` | `ขอบคุณ {name} ที่กดติดตามนะคะ` |
| `CHAT_TEXT` | `{name} บอกว่า {text}` |
| `CHAT_COOLDOWN` | `8` (วินาที — คนเดิมพิมพ์รัว ๆ อ่านแค่ทุก 8 วิ) |
| `EULER_API_KEY` | ว่าง (ถ้าโดนจำกัดการเชื่อมต่อ สมัครฟรีที่ eulerstream.com) |

กันป่วน: กรองคำหยาบ, ลบลิงก์, คิวคอมเมนต์ไม่เกิน 6 อัน, ผู้ติดตามคนเดิมขอบคุณครั้งเดียว, มีโดเนทเข้า → หยุดอ่านคอมเมนต์ 12 วิไม่ให้เสียงทับ

⚠️ ตัวเชื่อม TikTok ไม่ใช่ของทางการ ถ้า TikTok เปลี่ยนระบบอาจใช้ไม่ได้ชั่วคราว (ระบบโดเนทยังใช้ได้ปกติ)

## ขั้นที่ 1: ลองรันในเครื่อง

ไม่ต้องลงแพ็กเกจอะไรเพิ่ม (ใช้ Node 18 ขึ้นไป)

```bash
ADMIN_KEY=รหัสของเรา npm start
```

เปิด `http://localhost:3000`

## ขั้นที่ 2: ใส่ GIF และเพลงของเรา

เอาไฟล์ไปวางในโฟลเดอร์ `public/assets/`

- `alert.gif` → ภาพที่เด้ง
- `alert.mp3` → เพลงแจ้งเตือน (สั้น ๆ 3–5 วิกำลังดี)

ถ้าไม่ใส่ จะใช้อีโมจิ 🎉 + เสียงติ๊งแทนให้อัตโนมัติ
(ใช้ไฟล์ที่เรามีสิทธิ์ใช้ เช่นทำเองหรือจากเว็บแจกฟรีที่อนุญาตให้ใช้ในไลฟ์)

## ขั้นที่ 3: ใส่ใน OBS

1. Sources → **+** → **Browser**
2. URL: `https://เว็บของเรา/overlay.html`
3. ขนาด 800 × 600
4. ติ๊ก **Control audio via OBS** (เสียงจะเข้าไลฟ์)
5. ไปหน้า `/admin.html` กด **ยิงทดสอบ** → ต้องเด้งใน OBS

ตัวเลือกเพิ่มเติมใน URL overlay:
- `?vol=0.5` ปรับความดัง (0–1)
- `?gif=ลิงก์gif` ใช้ GIF จากที่อื่น
- `?debug` แสดงสถานะการเชื่อมต่อมุมซ้ายบน

## ขั้นที่ 4: ขึ้นออนไลน์ด้วย Render

1. อัปโค้ดขึ้น GitHub
2. Render → New → **Web Service** → เลือก repo
3. Build: เว้นว่าง หรือ `npm install` · Start: `npm start`
4. Environment Variables:

| ชื่อ | ค่า |
|---|---|
| `ADMIN_KEY` | รหัสแอดมิน (ตั้งให้ยาก ๆ) |
| `STREAMER_NAME` | ชื่อที่โชว์บนหน้าโดเนท |
| `MIN_AMOUNT` | ขั้นต่ำ (ค่าเริ่ม 10) |
| `BAD_WORDS` | คำหยาบเพิ่มเติม คั่นด้วย `,` |
| `PROMPTPAY_ID` | เบอร์ (10 หลัก) หรือเลขบัตรประชาชน (13 หลัก) ที่ผูก PromptPay |
| `PROMPTPAY_NAME` | ชื่อบัญชี (โชว์ใต้ QR ให้คนดูมั่นใจ) |

⚠️ Render แบบฟรีจะหลับเมื่อไม่มีคนใช้ ตอนเปิดครั้งแรกจะช้าประมาณ 1 นาที — เปิดหน้า admin ก่อนไลฟ์ให้มันตื่น

⚠️ ถ้ายังไม่ใส่ `PROMPTPAY_ID` = โหมดทดสอบ ใครมีลิงก์ก็กดเด้งได้ (มีกันกดรัว 5 วิ/คน)
